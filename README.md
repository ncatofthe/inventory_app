# Inventory App

Приложение для учета IT-оборудования.

Проект сделан как прикладная утилита для системного администрирования: хранение списка техники, базовый учет и быстрый доступ к информации по оборудованию.

## Для чего подходит

- учет компьютеров, периферии и другого IT-оборудования;
- первичная инвентаризация;
- небольшие внутренние процессы без тяжелой CRM;
- быстрый локальный инструмент под конкретную задачу.

## Запуск

```bash
python inventory_app.py
```
